# 次に必要な資料

登録済みの範囲は `docs/tax-data-status.md` を参照。

## 精度・機能に効くもの（優先順）
1. **国民年金の保険料額（令和8年度・令和7年度）** — 日本年金機構。個人事業主の手取りが出るために必須（現在は実額入力が必要）
2. **福山市の国民健康保険税の法定軽減（7割・5割・2割）の判定基準（令和8年度）** — 所得が低い世帯の国保税が実際より高く出るのを直す
3. **社会保険の扶養（健康保険の被扶養者の収入要件）と短時間労働者の適用拡大（106万円の壁）の公的資料** — 日本年金機構・協会けんぽの公式ページ（令和8年4月の認定基準の変更を含む）。配偶者側の壁を作る場合のみ
4. 国税庁 No.1524（暗号資産の売買損益の取扱い）— 暗号資産の売買を雑所得とする根拠の確認

## あれば
5. 令和9年度の住民税・国保税（公表され次第）
6. 協会けんぽ：福岡の令和7年度、東京の令和8年度、令和7年1〜2月分の旧料率
7. 雇用保険料率（労働者負担）
8. 所得税・住民税の端数処理（申告納税額の100円未満切捨など）
