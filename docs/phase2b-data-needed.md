# 次に必要な資料

登録済みの範囲は `docs/tax-data-status.md` を参照。

## 精度に効くもの（優先順）
1. **国税庁 No.1522（先物取引に係る雑所得等の課税の特例）・No.1523（損失の繰越控除）** — FX以外の先物・オプションの扱いと、繰越控除の要件
2. **国税庁 暗号資産（No.1525 など）** — 暗号資産の扱い（令和8年度以降の改正の有無も）
3. **令和8年分の住民税（令和9年度）の控除額の公表資料** — 現在は令和8年度の値で代用（福山市「所得控除の種類」が更新されたら）

## あれば
4. 協会けんぽ：福岡の令和7年度、東京の令和8年度（現在は他支部の平均で概算）、令和7年1〜2月分（令和6年度料率）
5. 雇用保険料率（労働者負担）、国民健康保険・国民年金（福山市）
6. 所得税・住民税の端数処理（申告納税額の100円未満切捨など）

フェーズ2の機能はそろっているため、フェーズ3（シミュレーション・壁・FX利確比較）に進める。
