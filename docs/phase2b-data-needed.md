# 次に必要な資料

登録済みの範囲は `docs/tax-data-status.md` を参照。国民年金（令和8年度）は日本年金機構で確認済み。国保の法定軽減は二次情報で登録済み（画面に注意書きを出している）。

## 公式資料に置き換えたいもの（精度の裏付け）
1. **福山市「国民健康保険税の軽減」（法定軽減の判定基準・令和8年度）** — 7割・5割・2割の基準額（二次情報の43万円・31万円・57万円）の裏付け。保険年金課の「国民健康保険税はどのように計算されますか？」のページなど（国保税の概要ページには基準額がない）
2. **日本年金機構 令和7年度の国民年金保険料額** — 令和7年分の年金額（任意）

## 機能を足すなら（使う場合のみ）
- **住宅ローン減税の自動計算**: 国土交通省の下位ページ（新築住宅・既存住宅・買取再販）の借入限度額・控除率・控除期間の表、国税庁「住宅借入金等特別控除」、住民税から控除される分の上限
- **株式等**: 国税庁の株式等の譲渡所得・配当所得・配当控除・損失の繰越控除、住民税の税率
- **雑損控除**: 国税庁「雑損控除」
- **ふるさと納税**: 総務省の控除上限額の計算式（二次情報の置き換え）
3. **社会保険の扶養（健康保険の被扶養者の収入要件）・短時間労働者の適用拡大（106万円の壁）の公的資料** — 日本年金機構・協会けんぽの公式ページ。配偶者側の壁を作る場合のみ
