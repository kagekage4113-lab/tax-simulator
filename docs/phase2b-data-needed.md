# 次に必要な資料（フェーズ2b の残り）

登録済みの範囲は `docs/tax-data-status.md` を参照。

## 優先
1. **社会保険料の概算率**（協会けんぽ・厚生年金・雇用保険の料率、国民健康保険・国民年金の保険料）— 未登録だと、実額を入力しない限り手取りが出ない
2. **FX・先物取引の税率と繰越控除**（国税庁 No.1521 など）— FXの税額が出ない
3. **復興特別所得税の原本**（国税庁 No.2260）— 現在は二次情報（2.1%）
4. **所得税の速算表（確定申告用・全区分）**（国税庁 No.2260）— 18,050,000円超と、年末調整用と同一かの確認
5. **令和8年分の住民税（令和9年度）の控除額** — 公表され次第（福山市「所得控除の種類」の更新）

## あると良い
6. 所得税の端数処理（申告納税額の100円未満切捨など）、住民税の端数処理
7. 特定親族の年齢要件・ひとり親/寡婦の所得要件（国税庁の資料）
8. 個人事業税：端数処理、業種一覧の細目、月割・繰越
