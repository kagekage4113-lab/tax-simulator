# フェーズ2b: 登録する税制データと必要な資料

エンジン（`src/calc/engine.js`）はフェーズ2aで完成済み。以下の値を **出典付きで** `src/data/taxYears/2025.js`（令和7年分）に登録すると、
画面の「データ未登録」が消えて税額・手取りが表示される。推測値は登録しない。

| 登録先キー | 内容 | 資料の例 |
|---|---|---|
| `incomeTax.brackets` | 速算表 `[{upTo, rate, deduction}]`（課税所得の区分・税率・控除額） | 国税庁 タックスアンサー No.2260 |
| `incomeTax.reconstructionRate` | 復興特別所得税の率（基準所得税額に対する率） | 国税庁 No.2260 など |
| `salaryDeduction.brackets` | 給与所得控除 `[{upTo, rate, add}]`（控除額 = 収入×rate + add、令和7年度改正後の最低保障額を含む） | 国税庁 No.1410 |
| `basicDeduction.incomeTax` / `.residentTax` | 基礎控除 `[{upTo(合計所得), amount}]`（令和7年度改正後） | 国税庁 No.1199、総務省・自治体の住民税の案内 |
| `residentTax.incomeRate` / `.perCapita` | 住民税の所得割率・均等割（森林環境税の扱いも要確認） | 総務省・自治体の案内 |
| `businessTax.rate` / `.mainDeduction` | 個人事業税の税率・事業主控除（業種別税率が必要なら業種ごとの表） | 都道府県税事務所の案内 |
| `rounding.*` | 端数処理（課税所得1,000円未満切捨、税額100円未満切捨 など）と根拠 | 国税庁・総務省 |
| `fx.incomeTaxRate` / `.residentTaxRate` | FXの税率（所得税15%＋復興税、住民税5%） | 国税庁 No.1521 など |
| `medical` | 医療費控除の足切り（10万円または所得の5%の小さい方）・上限 | 国税庁 No.1120 |
| `socialInsurance.estimate` | 社会保険料の概算率（会社員／国保）。出典が弱い場合は実額入力を前提にしてよい | 協会けんぽ・厚労省 |
| `deductions.*`（2b後半） | 配偶者控除・配偶者特別控除、扶養控除、特定親族特別控除、障害者・寡婦・ひとり親・勤労学生控除の段階表（所得税・住民税） | 国税庁 No.1191, 1180, 1160, 1160改正資料 ほか |

登録後は、資料に載っている計算例（年収と税額の組）を `tests/` に独立した期待値として追加して照合する。
