# 次に必要な資料（フェーズ2b の残り）

登録済みの範囲は `docs/tax-data-status.md` を参照。以下が揃うと、所得税の合計・住民税・手取りが画面に出る。

## 最優先（これが無いと税額・手取りが「—」のまま）
1. **復興特別所得税の率と適用期間**（国税庁 No.2260 または年末調整のしかた内の該当ページ）
2. **給与所得控除（収入220万円超）**（国税庁 No.1410 など令和8年分）
3. **住民税の所得控除額一覧**（令和8年度＝令和7年中の所得に対する分。基礎控除・配偶者・扶養・障害者・寡婦/ひとり親・勤労学生）
   - 福山市ページの「所得控除の種類」と「2026年度（令和8年度）から適用される主な市・県民税の税制改正点」
   - 住民税は「前年所得に対して翌年度課税」なので、**令和8年分の所得に対する住民税（令和9年度）** の控除額が必要。令和9年度の改正の有無も確認
4. **所得税の速算表（確定申告用・全区分）** 国税庁 No.2260（18,050,000円超と、年末調整用と同一かの確認）

## あると良い
5. 「特定親族」の年齢要件（特定親族特別控除の解説ページ No.1177 など）
6. 医療費控除（No.1120）、FXの税率と繰越（No.1521 ほか）
7. 令和7年分の同等資料（令和7年分の年末調整のしかた など）
8. 個人事業税：端数処理、業種一覧の細目（広島県資料の続き）
