# 次に必要な資料

登録済みの範囲は `docs/tax-data-status.md` を参照。

## 精度に効くもの（優先順）
1. **福山市「人的控除額の差額一覧表」**（`fukuyama.../2183.html` の「人的控除額の差額一覧表はこちら」のリンク先）— 住民税の調整控除（所得割が数千円〜多めに出る分）を反映するために必要
2. **協会けんぽ 令和7年度（令和7年3月分〜令和8年2月分）の保険料額表（広島）** — 令和7年分の社会保険料を正確にする（現在は令和8年3月分からの料率で代用）。令和8年1〜2月分の旧料率も同じ表
3. **所得税の速算表（確定申告用・全区分）**（国税庁 No.2260）— 18,050,000円超の区分と、年末調整用との同一性
4. **国税庁 No.1522（先物取引に係る雑所得等の課税の特例）・No.1523（損失の繰越控除）** — FX以外の先物・オプションと、繰越控除の要件
5. **国税庁 暗号資産（No.1525 など）** — 暗号資産の扱いの確認（令和8年度以降の改正の有無も）

## あれば
6. 雇用保険料率（労働者負担）、国民健康保険・国民年金（福山市）
7. 所得税・住民税の端数処理（申告納税額の100円未満切捨など）
8. 令和8年分の住民税（令和9年度）の控除額の公表資料
