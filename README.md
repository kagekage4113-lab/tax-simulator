# ざっくり手取り＆税金シミュレーター

収入・経費・控除を入力して、所得税・住民税・個人事業税・社会保険料・手取りの**目安**を出し、
「あと50万円稼いだら？」「今年利確するか来年に回すか」などを比較するスマホ優先のPWAです。
確定申告の代わりではなく、正確な申告税額を出すものではありません。

- サーバー・データベースなし。入力は端末のブラウザ（localStorage）にだけ保存され、外部へ送信されません。
- JSONで書き出し・読み込みができます。オフラインでも動きます（Service Worker）。
- 税制の数値は**公的資料で確認できたものだけ**を、出典付きで登録しています。資料がない項目は「未登録」と表示し、推測では計算しません。

## 使い方（開発）
```bash
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト（税額は手計算の期待値で検証）
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果を確認
```

## 公開（スマホで使う）
`npm run build` で出た `dist/` を、静的ファイルを置ける場所（GitHub Pages・Netlify・Cloudflare Pages など）に置くだけです。
`base` は相対パスなので、サブディレクトリ配下でも動きます。HTTPSで開き、ブラウザの「ホーム画面に追加」でアプリとして使えます。
更新は、ビルドごとにService Workerのキャッシュ名が変わるため、次回起動時に新しい版へ切り替わります。

## 構成
| 場所 | 内容 |
|---|---|
| `src/calc/` | 税額計算エンジン（画面に依存しない）。`engine.js`＝所得・控除・税額・社会保険料・手取り、`simulate.js`＝比較・壁・FX利確、`walls.js`＝壁の定義 |
| `src/data/` | 収入区分・控除の設定データ、年度別税制データ（`taxYears/`）。出典ID付き |
| `src/core/` | 入力データのスキーマ・検証・保存（localStorage / JSON） |
| `src/ui/` | 画面 |
| `docs/tax-sources/` | 公的資料の原本（PDF）。登録した値の根拠 |
| `docs/tax-data-status.md` | 税制データの確認状況（確認済み／一部／代用／二次情報／未確認） |
| `docs/phase2b-data-needed.md` | 次に必要な資料 |
| `tests/` | テスト。期待値は実装から生成せず、資料の表や手計算で用意 |

## 対応範囲（令和7年分・令和8年分）
- 給与・事業・不動産・雑所得・暗号資産の総合課税、FX・先物の申告分離課税（繰越損失は年ごと・3年）
- 所得控除（基礎・配偶者・扶養・特定親族特別・障害者・寡婦/ひとり親・勤労学生・社会保険料・手入力の控除）、税額控除（手入力）
- 所得税、住民税（調整控除・非課税判定）、個人事業税、社会保険料（協会けんぽ・国保＋国民年金の概算／実額入力）
- 生命保険料控除・地震保険料控除の自動計算、ふるさと納税の寄附上限額の目安（二次情報）
- 追加収入・経費の比較と限界負担率、壁の表示、FXの利確タイミング比較、確定申告の要否（参考）

## 概算であることの前提
住民税・国保税は福山市（広島県）の値、事業税は広島県の値です。協会けんぽは広島・福岡・大阪（ほかは平均で概算）。
令和8年分の住民税の控除額などは、公表前のため令和8年度の値で代用しています。各画面の「計算の前提」に注意書きが出ます。

## 未対応
株式等の譲渡・配当（簡易扱い。NISAは非課税のため入力不要）、配当控除・雑損控除・住宅ローン控除の自動計算（住宅ローン控除は税額控除として手入力）、
自治体別の国保料・住民税。いずれも公的資料の入手後に対応します。
