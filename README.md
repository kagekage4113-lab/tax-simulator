# 税金メーター（あと○円稼いだら、いくら残る？）

収入・経費・控除を入力して、所得税・住民税・個人事業税・社会保険料・手取りの**目安**を出し、
「あと50万円稼いだら？」「今年利確するか来年に回すか」などを比較するスマホ優先のPWAです。
確定申告の代わりではなく、正確な申告税額を出すものではありません。

> **ベータ版です。** 2026年10月時点の公的資料に基づく参考情報で、正確性・最新性を保証するものではありません。利用によって生じた損害について責任を負いません。申告や手続きは、国税庁・自治体・専門家の案内をご確認ください。

**使う**: https://kagekage4113-lab.github.io/tax-simulator/ （スマホは「ホーム画面に追加」でアプリのように使えます）
**気づいた点・不具合**: このリポジトリの [Issues](https://github.com/kagekage4113-lab/tax-simulator/issues) へ。入力した内容は書かないでください（個人情報になります）。

## 使い方（3つの画面）
1. **入力**: 住んでいる場所（協会けんぽの支部）・年齢・収入・家族を入れます。赤い欄は、まだ答えていない項目です。
2. **確認**: 税金と手取りの目安、世帯の見取り図（誰が非課税か）、控除の余り（あと何円まで税額0円か）を見ます。
3. **調整**: 「あと○円稼いだら？」「経費を変えたら？」を試したり、保険料・医療費などの控除を足したりします。

例（東京・34歳・会社員・年収480万円）に、副業の収入100万円・経費30万円を足すと、令和8年分の目安は、所得税+約5.7万円・住民税+7万円で、手取りは約57万円増えます。

## このツールの限界（先に読んでください）
- 税理士による試算ではなく、すべての収入・控除・地域の組み合わせを反映したものではありません。
- **地域**: 住民税・国民健康保険料・個人事業税は**東京23区の標準の値**です。全国の自治体には対応していません。
- **社会保険料**: 会社員は協会けんぽの料率による概算で、賞与なし（年収を12か月に均等に分けた報酬）・雇用保険料なしです。健保組合・共済の人は差が出ます。
- **手取り**: その年の収入に対する税金・社会保険料を引いた年間の目安です。毎月の天引き（住民税は前年の所得が基準）とは時期がずれます。
- **高年収・役員**: 役員報酬、高年収の人の特例などは対象外・未検証です。
- **未対応**: 配当控除、一般株式、消費税・インボイス、住宅ローン控除の自動計算、勤務先の社会保険の加入判定、介護保険料・高額療養費の金額 など（下の「未対応」も参照）。
- 確認できていない値は、推測せず「未確認」と表示します。確認状況は `docs/tax-data-status.md` にあります。

## 特徴
- サーバー・データベースなし。入力は端末のブラウザ（localStorage）にだけ保存され、外部へ送信されません。
- バックアップの保存・読み込みができます（スマホは共有メニューからファイルに保存。コピーして貼り付けでも読み込めます）。オフラインでも動きます（Service Worker）。
- 税制の数値は**公的資料で確認できたものだけ**を、出典付きで登録しています。資料がない項目は「未登録」と表示し、推測では計算しません。

## 使い方（開発）
```bash
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト（税額は手計算の期待値で検証）
npm run build    # dist/ に静的ファイルを出力
npm run preview  # ビルド結果を確認
```

## 公開（スマホで使う）
`npm run build` で出た `dist/` を、静的ファイルを置ける場所（GitHub Pages・Netlify・Cloudflare Pages など）に置くだけです。
`base` は相対パスなので、サブディレクトリ配下でも動きます。HTTPSで開き、ブラウザの「ホーム画面に追加」でアプリとして使えます。
更新は、ビルドごとにService Workerのキャッシュ名が変わるため、次回起動時に新しい版へ切り替わります。

## 構成
| 場所 | 内容 |
|---|---|
| `src/calc/` | 税額計算エンジン（画面に依存しない）。`engine.js`＝所得・控除・税額・社会保険料・手取り、`simulate.js`＝比較・壁・FX利確、`walls.js`＝壁の定義 |
| `src/data/` | 収入区分・控除の設定データ、年度別税制データ（`taxYears/`）。出典ID付き |
| `src/core/` | 入力データのスキーマ・検証・保存（localStorage / JSON） |
| `src/ui/` | 画面 |
| `docs/tax-sources/` | 公的資料の原本（PDF）を置く場所。**原本はリポジトリに含めていません**（手元にのみ保管）。出典の名前・URLは `src/data/taxYears/local.js` の `SRC` に記録 |
| `docs/tax-data-status.md` | 税制データの確認状況（確認済み／一部／代用／二次情報／未確認） |
| `docs/phase2b-data-needed.md` | 次に必要な資料 |
| `tests/` | テスト。期待値は実装から生成せず、資料の表や手計算で用意 |

## 対応範囲（令和8年分）
画面が対応するのは**令和8年分**だけです。令和7年分のデータは、計算ロジックを手計算で検証するテストのために内部に残してあり、画面からは選べません（令和7年分の保存データは令和8年分として読み込みます）。住民税・国保・個人事業税は東京23区の標準の値だけで計算します（地域の切り替えはありません）。
- 給与・事業・不動産・雑所得・暗号資産の総合課税、FX・先物／上場株式等の申告分離課税（損失の繰越は区分ごと・年ごと・3年）
- 所得控除（基礎・配偶者・扶養・特定親族特別・障害者・寡婦/ひとり親・勤労学生・社会保険料・手入力の控除）、税額控除（手入力）
- 所得税、住民税（調整控除・非課税判定）、個人事業税、社会保険料（協会けんぽ・国保＋国民年金の概算／実額入力）
- 生命保険料控除・地震保険料控除・雑損控除の自動計算、ふるさと納税の寄附上限額の目安（二次情報）
- 追加収入・経費の比較と限界負担率、壁の表示、FXの利確タイミング比較、確定申告の要否（参考）

## 概算であることの前提
住民税・国保・個人事業税は東京23区の値で計算します（ほかの自治体は近い値での概算。国保は実額入力が確実です）。協会けんぽは全国47支部の料率（令和8年度。令和7年度は一部代用）です。
令和8年分の住民税の控除額などは、公表前のため令和8年度の値で代用しています。各画面の「計算の前提」に注意書きが出ます。

## 未対応
一般株式等（上場株式等以外）、配当控除（総合課税を選ぶ配当）、住宅ローン控除の自動計算（確定申告書等作成コーナーの計算結果を税額控除として手入力）、
雑損失の繰越控除、自治体別の国保料・住民税。
